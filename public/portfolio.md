## Ключевой проект

### Senlo — AI-ассистент в Telegram

Основатель и единственный разработчик. Senlo — AI-агент, который работает прямо в Telegram-аккаунте клиента. Не бот с синей плашкой, а ассистент, которого не отличишь от живого менеджера.

- Отвечает клиентам за 2-3 секунды от имени владельца
- Работает строго по загруженным документам — не фантазирует
- Квалифицирует лидов и передаёт горячих клиентов менеджеру с полным контекстом
- Синхронизация с AmoCRM

Мульти-тенантная SaaS-платформа. React 19, NestJS, PostgreSQL, Redis, Gemini API с RAG-движком. Весь стек — один разработчик.

### Платформа умных парковок

Веб-приложение с компьютерным зрением: распознавание автомобилей, отслеживание мест, управление доступом в реальном времени.
