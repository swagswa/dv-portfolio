# Daniil Volkov — Creative Tech Portfolio

Personal portfolio showcasing AI automation, visual content creation, and fullstack web development.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`

## Deploy

Configured for Vercel deployment.
